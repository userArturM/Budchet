# Семейный бюджет

Веб-приложение для семейного бюджета. Работает в браузере, устанавливается на экран «Домой» iPhone и работает без интернета. Сборка не нужна: это один файл `index.html`.

## Как запустить через GitHub Pages
1. Создайте на github.com новый репозиторий (например, `family-budget`). Можно приватный, если у вас платный план, иначе публичный. Данные бюджета в репозиторий не попадают, они хранятся в телефоне.
2. Загрузите в корень репозитория все файлы из этого архива (Add file → Upload files). Папку `icons` и файл `.nojekyll` загружайте тоже.
3. Откройте Settings → Pages. В разделе Build and deployment выберите Source: Deploy from a branch, Branch: `main`, папка `/ (root)`, нажмите Save.
4. Через 1–2 минуты там появится адрес вида `https://ВАШ-ЛОГИН.github.io/family-budget/`.
5. Откройте адрес на iPhone в Safari → «Поделиться» → «На экран „Домой“».

## Что умеет
Операции и счета, переводы, категории и лимиты, цели, кредиты, регулярные платежи, карманные деньги детей, прогноз, план 50/30/20, отчёт и экспорт CSV, PIN-код, резервная копия.

## Важно
- Данные хранятся в браузере каждого телефона. Для переноса используйте «Лимиты» → «Резервная копия и перенос».
- В этой версии нет общего бюджета с автосинхронизацией и сканирования чеков: они работают только в версии на claude.ai.
- Если очистить данные Safari, бюджет пропадёт. Делайте резервную копию.
- Чтобы выпустить обновление, замените `index.html` и поднимите версию в `sw.js` (`fbudget-v1` → `fbudget-v2`).
